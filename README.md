# 軽作業レベルアップ（複数管理者・工賃計算）

このフォルダーは、添付されていたFirebase版「軽作業レベルアップアプリ」を元にした一式です。既存のレベル・EXP・目標・成長記録を残し、工程単価×完了数量の工賃表示と、複数管理者の利用者一覧を加えています。

## できること

- 利用者ごとのログインと、本人だけが自分の記録を変更できるルール
- 管理者は全利用者の工賃合計を確認し、管理者の追加・解除ができる
- 管理者が分野・工程ごとの単価を登録し、作業記録時に登録単価を適用
- 作業記録に単価、数量、工賃の計算結果を保存
- 元アプリのレベル、経験値、目標、成長履歴の機能

## Firebaseへの設定手順

1. 元アプリと同じFirebaseプロジェクトを使う場合は、念のためFirestoreのデータをバックアップします。
2. Firebase ConsoleでAuthenticationの「メール/パスワード」とFirestoreを有効にします。
3. `firebase-config.js` の6項目を、自分のFirebase Webアプリ設定に置き換えます。FirebaseのWeb設定値はブラウザに含まれる公開設定値です。サービスアカウント鍵や秘密鍵はここに貼らないでください。
4. Firebase CLIでプロジェクトを選び、このフォルダーから `firebase deploy --only firestore:rules,functions,hosting` を実行します。初回は `firebase login` と `firebase use --add` が必要です。
5. 初回の管理者を1人だけ、Firebase ConsoleのFirestoreで設定します。Authenticationの利用者一覧から自分のUIDを確認し、`admins` コレクションに同じUIDのドキュメントを作成します。ドキュメント本文は `{ "grantedAt": (timestamp), "grantedBy": "bootstrap" }` で構いません。
6. HostingのURLを開いてログインします。管理者メニューから、登録済み利用者を追加管理者にしたり、解除したりできます。最後の管理者は解除できません。
7. 管理者メニューの「工程単価の設定」で分野・工程・単価を登録します。作業記録の単価欄には登録済み単価が入ります。完了数量を入力すると、工賃は「単価×数量」で記録されます。

## 既存利用者データについて

この一式は元アプリの `users/{UID}` 保存形式を維持します。既存のログイン利用者は同じFirebaseプロジェクトにデプロイすれば、これまでのレベルや作業履歴を引き継げます。新しいフィールドのない過去記録は工賃0円として表示されます。旧形式のFirestoreルールは置き換わるため、必ず同梱の `firestore.rules` を適用してください。

## 注意点

この仕組みは作業量から工賃を集計するためのものです。支給額を確定する前に管理者が記録を確認してください。工程単価は管理者のみ変更できます。利用者の記録は本人が編集できるため、監査済みの給与台帳として使う場合は、記録をサーバー側で確定する運用へ追加変更が必要です。

今回確認できたZIPは「軽作業レベルアップアプリ」でした。「PC Skill Growth」は別アプリで、元ファイルがないため、既存機能に統合した版はまだ作っていません。この一式をPC Skill Growthへそのまま上書きしないでください。そちらのファイル一式を受け取れば、同じ権限・工賃機能をアプリの実装に合わせて移植できます。
