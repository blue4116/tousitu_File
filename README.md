# まいにち血糖ケア

食事写真・文章・血糖値を記録し、日ごとの変化と週単位の傾向を確認するWebアプリです。

## Vercelへデプロイ

このリポジトリをVercelへインポートし、Root Directoryをリポジトリ直下に設定してデプロイします。`api/` 内の推定APIもVercel Functionsとして動作します。GitHub PagesやFirebase Hostingだけでは、これらのAPIは実行されません。

VercelのProject Settings → Environment Variablesに `OPENAI_API_KEY` を登録してから再デプロイしてください。OpenAI APIキーはフロントエンドやGitHubへ書き込まないでください。必要な場合のみ `OPENAI_VISION_MODEL` と `OPENAI_TEXT_MODEL` を設定できます（既定値: `gpt-4.1-mini`）。

## 栄養推定

食事の文章欄に飲食店メニュー、市販品・既製品の商品名、サイズ、個数、栄養表示を入力し、「文章から栄養を推定」を押すと、1回分のカロリーと栄養素を概算します。写真からも推定でき、油・ソースなどはメモの内容を別カロリーとして追加します。推定値は保存前に確認・修正してください。数量や商品情報が不足する場合、誤差が大きくなります。

## データとプライバシー

- 食事・血糖値・振り返りコメント・写真はブラウザー内の `localStorage` に保存します。別の端末やブラウザーとは同期せず、ブラウザーのデータ消去で失われます。
- 写真と調味料メモは写真推定ボタンを押した時に、文章は文章推定ボタンを押した時に、推定処理のため解析API経由でOpenAIへ送信されます。画面にも送信内容を表示しています。不要な個人情報は入力しないでください。
- 通知はブラウザーの許可が必要で、ページを開いている間に指定時刻を確認します。
- 栄養値は目安であり、診断・治療の代わりではありません。

## 対応機能

- 昼食・間食を含む食事分類と、過去日時での記録
- 食事の編集・削除、写真の保存・拡大表示、コメント全文表示
- 血糖値の測定タイミング選択と、日ごとの推移・平均グラフ
- 食事カロリー・栄養バランスのダッシュボードと週次レポート
- 食事・血糖値の通知と、記録の振り返りコメント
